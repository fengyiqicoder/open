# Privacy Policy — Default Browser Switcher

_Last updated: 2026-06-20_

Default Browser Switcher ("we", "our", "us") respects your privacy. Default Browser Switcher is a Mac app that you can set as your default browser so it can route each link you open to the right browser by your own rules. This policy explains what data the app handles.

## 1. Data we collect

**None.** Default Browser Switcher does not collect, transmit, or share any personal data. There is no account, no sign-in, and no analytics. The app never records, stores, or transmits the links you open — each link is passed straight to the browser you chose.

## 2. Where data is stored

All app data and settings — your routing rules and fallback browser choice — stay **locally on your Mac** in standard app preferences. We do not run a server, use iCloud sync, or use any third-party storage.

## 3. Permissions

| Permission | Used? | Purpose |
|---|---|---|
| Accessibility | ❌ | Not used — Default Browser Switcher is fully sandboxed |
| Input Monitoring | ❌ | Not used |
| Network | ❌ | The app makes no network connections of its own |

## 4. How links are handled

When you set Default Browser Switcher as your default browser, macOS hands it the links you click. The app reads only the URL, matches it against the rules you created, and opens it in the browser you picked. The URL is used in memory at that moment only and is never logged or sent anywhere.

## 5. Children's privacy

The app is a general-purpose utility and does not knowingly collect any data from anyone, including children under 13.

We may update this policy; material changes will be posted here with a new date.

# Support — Default Browser Switcher

Need help with Default Browser Switcher? You're in the right place.

## Quick start

1. Open **Default Browser Switcher**.
2. Click **Set as Default** and confirm in the macOS dialog that appears.
3. Open the **Browsers** tab and pick a **fallback browser** (used when no rule matches).
4. Open the **Smart Rules** tab and add rules — e.g. links containing `github.com` open in Safari, links containing `figma` open in Chrome. The first matching rule wins.

That's it — every link you click now opens in the right browser automatically.

## FAQ

**Q: How do I make it my default browser?**
Click **Set as Default** in the app, then confirm in the system dialog. You can also set it under  Apple menu ▸ System Settings ▸ Desktop & Dock ▸ Default web browser.

**Q: A link opened in the wrong browser.**
Check your Smart Rules — the first rule whose text is contained in the link wins. If no rule matches, the link opens in your fallback browser. Make sure Smart Routing is switched on.

**Q: Does it work with Chrome, Safari, Firefox, Edge, Brave, Arc…?**
Yes. Any browser installed on your Mac is detected automatically and can be used as a rule target or fallback.

**Q: Does it collect my browsing data?**
No. The app never records or transmits the links you open. See our [Privacy Policy](PRIVACY.md).
